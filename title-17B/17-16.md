# N.J.S. 17B:17-16. Separability of provisions

If any provision of this Code or the application thereof to any person or circumstance is held invalid, the invalidity shall not affect other provisions or applications of this Code which can be given effect without the invalid provision or application, and for this purpose the provisions of the Code are separable.

Source: L.1971, c. 144, s. 17B:17-16.
