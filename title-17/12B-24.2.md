# N.J.S. 17:12B-24.2. Powers of out-of-State, State association

93\. a. An out-of-State association that opens, occupies or maintains a branch office in this State shall have in this State only the powers a State association has in this State.
- b. A State association that owns, occupies or maintains a branch office outside this State shall have in that state such additional powers as permitted to associations chartered in the state in which the branch is located.

Source: L.1996,c.17,s.93.
